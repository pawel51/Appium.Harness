# Known issues — Appium.Harness

Resolved bugs specific to **this library's** code or conventions. Bugs that are true of the stack
itself (Appium, XCUITest, UIAutomator2, WebDriver, .NET MAUI) live in `~/.claude/knowledge/`.

What this folder is and how to add to it: [`README.md`](README.md).
Entry schema: `~/.claude/knowledge/SPEC.md`.

Search the full text before debugging — error string first:

```sh
rg -i -- "<exact error string>" docs/knowledge ~/.claude/knowledge
```
